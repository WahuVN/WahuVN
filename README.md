## How I work

- **Context-first language review:** check meaning, tone, pronouns, terminology and culturally natural Vietnamese.
- **Human-guided AI workflows:** use AI-assisted drafting, comparison and review while keeping the final linguistic judgment with a human.
- **Evidence-based QA:** document observed defects, separate verified behavior from assumptions and retest changes.
- **Reliable delivery:** maintain readable documentation, release notes and clear installation or rollback steps.

**Technical toolkit:** C# / .NET / WPF, Python, Rust, TypeScript / JavaScript, React, SQLite, Git and automated testing.
